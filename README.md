# Shafiya Naaz — Visual GitHub Pages Portfolio

1. Create a **public** repo named `ShafiyaNaaz27.github.io` (or `YOUR_USERNAME.github.io`).
2. Upload everything in this folder to the repo root.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/(root)`.
4. Replace `YOUR_EMAIL@example.com` in `index.html`.
5. Add your resume as `assets/resume.pdf`.
6. Add more certificates to `assets/certificates/` and offer letters to `assets/offer-letters/`.

No build step is required.
